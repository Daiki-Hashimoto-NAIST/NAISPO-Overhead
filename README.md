# NAISPO-Overhead

「もぐもぐ モンスター」は、落ちてくる食べ物を左右のモンスターに届けるUnityの実験プロジェクトです。淡い草原の背景と丸い文字で、子どもが遊ぶ画面を作っています。Kinectを使う場合は、真上から見た輪郭の向きで棒を操作します。両腕を広げたまま体を回す操作を試すために作りました。既存の[NAISPO](https://github.com/Daiki-Hashimoto-NAIST/NAISPO)とは独立しています。

起動直後はKinectを使わないデモです。天井や机の上にKinectを固定した状態での認識精度・遊びやすさは、まだ実機で検証していません。

## 起動方法

Windows 64bitとUnity **6000.6.5f1** を使用します。

1. このプロジェクトをUnityで開きます。
2. メニューの `Overhead / Build Windows` を選びます。
3. ビルドが終わったら、プロジェクト直下の `Run-Overhead.cmd` を実行します。

ビルド先は `Builds/Windows` です。実行時は `Launch-Overhead.ps1` が `%USERPROFILE%\NaispoOverheadRuntime` にコピーして起動します。Kinectのライブラリを日本語を含むパスから実行する問題を避けるため、コピー先は半角英数字だけのパスにしています。Windowsのユーザー名に日本語がある場合は、スクリプトの `runtimeFolder` を変更してください。

ビルド済みの実行ファイルはGit管理に含めていません。

## 遊び方

画面中央の棒を傾け、上から落ちてくる食べ物を左右のモンスターに届けます。いちごは左、さかなは右のモンスターが正解です。足元の絵が、それぞれの好物を表しています。

食べ物はゆっくり回転しながら落ち、棒で弾くと飛ぶ方向に勢いよく回転します。

好物が届くと満足した顔になり、少し跳ねます。違う食べ物が届くと困惑した顔になり、体を小さく揺らします。表情は約1.6秒で通常に戻ります。

正しく届けた数は画面上部の「ごちそう」に表示します。Kinectの接続や細かい調整は、右上の「せってい」から開けます。設定画面を開いている間は、ゲームの進行が止まります。

| デモの操作 | 動作 |
| --- | --- |
| `A` / `←` | 左へ送る向きに傾ける |
| `D` / `→` | 右へ送る向きに傾ける |
| ゲーム領域で左クリックしたまま左右にドラッグ | マウスの横位置で傾きを変える |
| `ひとやすみ` | 一時停止する。`つづける` で再開 |
| `Escape` | 一時停止・再開。設定画面では設定を閉じる |
| `せってい` → `はじめから` | 得点と食べ物、モンスターの表情をリセットする |

## Kinectで試す

Azure Kinect DKを真下に向けて固定し、床または机を映します。先にNAISPOなど、Kinectを使っているアプリを閉じてください。

1. 右上の `せってい` を開き、床向けの `ゆか・からだ`、または机向けの `つくえ・て` を選びます。
2. 撮影範囲から人や手を出し、背景だけの状態にします。
3. `Kinect をつなぐ` を押し、30フレーム分の背景計測が終わるまでそのまま待ちます。
4. 床の場合は撮影範囲に入り、両腕を広げてゆっくり体を回します。設定画面のプレビューで、抽出された輪郭と、その向きを示す線を確認します。
5. `あそびに もどる` を押して遊びます。

カメラや背景を動かしたら、範囲を空けて `背景を とりなおす` を押してください。Kinectの入力中に `ゆか・からだ` と `つくえ・て` を切り替えたときも、背景を計測し直します。`マウス・キー` でデモに戻れます。

| 設定 | 内容 |
| --- | --- |
| `ゆか・からだ` | 背景との差が300〜2200 mmの部分を抽出 |
| `つくえ・て` | 背景との差が20〜250 mmの部分を抽出 |
| `ひくいところ` / `たかいところ` | 抽出する差の下限・上限を調整 |
| `左右反転` | 深度プレビューと入力軸を左右反転 |
| `回転反転` | ゲームへ伝える回転方向を反転 |

高さは「背景の深度 − 現在の深度」で求めています。真下向きの固定カメラを前提とした値で、床や机の傾きを補正する処理はありません。

## 認識の範囲

背景より手前にある部分を抜き出し、つながった領域のうち最大のものから、細長く伸びる向きを推定します。骨格認識や手の識別はしていません。左右の手や、体の正面・背面も区別できません。

机で試す場合も、離れた両手を1組として扱う機能はありません。最大の領域だけを見るため、片方の手や腕の向きを試す用途です。

腕を閉じて輪郭が丸くなったときや、体の一部が隠れて軸を求められないときは、食べ物の動きを一時停止します。深度フレームが0.5秒以上届かない場合も停止します。近くの物が体とつながって映ると、推定する向きがずれることがあります。

## 構成と依存関係

| 場所 | 内容 |
| --- | --- |
| `Assets/Scripts/OverheadDepthSource.cs` | Kinectから深度画像を取得 |
| `Assets/Scripts/DepthAnalyzer.cs` | 背景計測、輪郭の抽出、軸の推定 |
| `Assets/Scripts/OverheadApp.cs` | 食べ物の動き、仕分けの判定、入力と一時停止 |
| `Assets/Scripts/OverheadApp.View.cs` | 背景、モンスター、日本語UI、設定画面の描画 |
| `Assets/Scripts/GameLayout.cs` | 画面サイズに合わせた表示とマウス座標の変換 |
| `Assets/Resources/Monsters` | 左右のモンスターと通常・満足・困惑の表情画像（計6枚） |
| `Assets/Resources/Food` | いちごとさかなの画像 |
| `Assets/Resources/Fonts/RoundedJapanese.ttf` | 日本語フォントのZen Maru Gothic Bold |
| `Assets/Editor/MonsterTextureImporter.cs` | モンスターと食べ物の透過・画質設定 |
| `Assets/Tests/Editor` | 合成深度データなどを使うテスト |
| `Assets/Editor/OverheadSetup.cs` | シーン生成とWindowsビルド |
| `Assets/Plugins/AzureKinect` | Sensor SDKの実行用DLL |

Azure Kinect Sensor SDK 1.4.2由来の `Microsoft.Azure.Kinect.Sensor.dll`、`k4a.dll`、`depthengine_2_0.dll` を同梱しています。Body Tracking SDK、ONNXモデル、Git LFSは使いません。

SDKのライセンスは `Documentation/Licenses`、同梱DLLのサイズとSHA256は `Documentation/SDK_COPY_MANIFEST.json` に記録しています。

画面の文字にはZen Maru Gothic Boldを使用しています。ライセンスはSIL Open Font License 1.1です。原文は `Documentation/Licenses/ZenMaruGothic-OFL.txt`、取得元とファイルの情報は `Documentation/Licenses/ZenMaruGothic-source.md` にあります。

## 確認済みの動作

2026年10月21日、草原の背景・日本語UI・丸ゴシックを加えた版で52件のテストとWindowsビルドが成功しました。デモで食べ物と棒の回転、マウス操作による仕分けと得点、設定スライダー、一時停止ボタンと再開ボタンを確認しました。画面比率が変わったときの表示座標とマウス座標、回転中も画像の中心がずれないことは自動テストで確認しています。

2026年10月21日、モンスター・いちご・さかなの画像を組み込んだWindows版のビルドが成功しました。デモでいちごを左、さかなを右へ送ったときの得点と満足顔、違う食べ物を送ったときの困惑顔を確認しました。モンスターの通常表情と、得点リセット時に通常へ戻る動作も確認済みです。

食べ物の回転を加えた版もビルドし、落下中・棒で弾いた後の回転表示と左右への仕分けをデモで確認しました。

2026年10月16日、Unity 6000.6.5f1で40件のテストとWindowsビルドが成功しました。合成深度画像からの背景差分と軸の推定、180度回転しても同じ軸として扱う処理、玉と棒の接触判定を検証しています。

このPCではデモ操作による仕分け・得点と、Azure Kinectからの深度入力、背景計測後に軸を検出できない間の一時停止を確認しました。真上からの認識精度を確認した結果ではありません。
